# Level design guide

Step-by-step guide to building a map alone in the editor. Written in M7.4 once the template, markers and validator exist.

1. Duplicate the template (`game/maps/_template/map_template.tscn`)
2. Paint terrain
3. Place markers
4. Set up the `MapDefinition`
5. Run the map validator
6. Play from the editor

## Design rules (from Jake's research)
- One new mechanic per map.
- Keep rout maps to 40% or fewer.
- Telegraph reinforcements.
- Bosses should teach something, and should move or threaten an area rather than sit on a throne.
